# Kemplang Bakar Pak Harun — Website Digital Branding UMKM

Website promosi **Kerupuk Kemplang Bakar Pak Harun** untuk menampilkan produk makanan tradisional Palembang, kisah usaha, dan informasi pemesanan secara lebih menarik.

## Kebutuhan yang diselesaikan

Pembeli potensial memerlukan informasi sederhana mengenai produk, ukuran/paket, proses pembuatan, serta cara menghubungi penjual tanpa harus meminta daftar produk berulang kali.

## Fitur website

- **Hero produk** dan pengenalan identitas UMKM.
- Informasi usaha dan cerita proses pembuatan kemplang.
- **Daftar harga / paket** berukuran kecil, sedang, dan besar.
- Ajakan pemesanan dan tombol kontak.
- Informasi lokasi serta kanal komunikasi usaha.
- Animasi saat scroll dan tampilan visual responsif.

## Teknologi

**HTML**, **JavaScript**, **Tailwind CSS melalui CDN**, **AOS (Animate On Scroll)**, Google Fonts, serta Remix Icon. Implementasi utama menggunakan `index.html` dengan aset gambar pada repository.

## Hasil

Landing page promosi yang menyusun informasi produk dan jalur kontak secara terarah. Ini adalah **website digital branding UMKM**, bukan aplikasi checkout dengan sistem pembayaran terintegrasi.

**Konteks:** pengembangan website dan materi pemasaran digital UMKM lokal.
